# Ревизия кода, 22 октября 2026

Задача: найти слабые места, ошибки, лишний и неоптимальный код, логические ошибки интерфейса — и исправить их. Формат данных и папки проектов не менялись: ничего переносить не нужно.

## Логические ошибки и ошибки интерфейса

- **Группа, потерявшая последний узел, прыгала в начало координат.** В `retainGroups` позиция рамки считалась как `Math.min(24, …минимум по узлам…) - 24`, то есть всегда не больше нуля. Теперь рамка остаётся там, где были её узлы.
- **Недописанное число отменяло значение или показывало ошибку.** Поле `type=number` отдаёт пустую строку, пока введено `-` или `1e`. Узел Number сохранял при этом `0`, а слот — ошибку «значение не соответствует типу слота» красным тостом. Теперь правка ждёт целого числа (`validity.badInput`), а в правой панели неготовое число и неверный JSON сообщаются в самой форме, без тоста.
- **Клик по заголовку группы записывал правку.** У перетаскивания рамки не было порога смещения, поэтому любой клик отправлял `PUT layout`, создавал шаг отмены и перезагружал граф. Добавлен тот же порог в 3 px, что у узлов.
- **Рамка выделения не находила провода ни в одном стиле, кроме «Bezier 50 %».** `crossedEdges` считал кубическую кривую с жёстко вписанным изгибом. Теперь точки берутся из той же геометрии, которая рисуется (`edgePoints`), и проверяется пересечение отрезка с прямоугольником, то есть попадание не зависит от стиля и изгиба.
- **Клавиша панели свойств (N) не работала на холсте.** Общий обработчик пропускает события из `#canvas`, а в списке действий холста этого действия не было, так что на странице, где панель и находится, клавиша не делала ничего.
- **Провалившийся запуск оставлял тулбар в состоянии «Running…»** с выключенной кнопкой Run и узлами в состоянии «выполняется» до следующей перезагрузки графа.
- **На миникарте провода типов `int`, `signal` и `any` были серыми:** читался токен `--c-int`, которого нет. Добавлено сопоставление типа и цвета (`TYPE_TOKENS`) — то же, что в `canvas.css`.
- Сообщение «Script did not return a value for …» выдавалось для **любого** узла, не только для скрипта.
- Поиск падал на заметке без текста (файлы данных можно править руками, поэтому такое возможно).
- **Tab в поле кода не выпускал клавиатуру.** Теперь Tab по-прежнему делает отступ, а Escape, затем Tab — переходит к следующему элементу.
- `insertPorts` падал бы на узле без списка портов.

## Неоптимальный код

- **`server.js` обходил всё дерево `data/` раз в секунду всегда** — даже когда ни одна страница не открыта, — и пересканировал его целиком после каждой записи. Теперь опрос идёт только при открытых страницах; после записи обновляются лишь затронутые ключи; вернувшаяся страница получает чистую базу (а не лавину «изменилось»); отвалившиеся подписчики отбрасываются; слишком большой запрос обрывается.
- **`Editor.connections` строил полный снимок графа на каждое изменение** (а снимок — это диагностика и поиск компонент сильной связности). Удаление пачки проводов из 50 связей строило 50 снимков. Теперь удаления обходятся одним снимком на пакет, а добавления — как раньше, по одному (каждое меняет связность). `splitConnections` тоже брал снимок на каждую точку.
- **Удаление выделения запрашивало весь граф по разу на каждую выбранную группу.** Вложенные группы теперь отбрасываются локально.
- **`GET projects` и `GET projects/{id}` читали документ каждого workflow,** чтобы посчитать узлы, а `node_count` нигде не показывался. Убрано вместе с полем `busy`, которое всегда было `false`.
- **Перетаскивание, растягивание и панорамирование перерисовывали всё на каждое событие указателя** (включая пересборку всех рамок через `innerHTML` и поиск провода под узлом по геометрии SVG). Теперь это идёт через `onNextFrame` — не чаще одного раза на кадр.
- Импорт в Библиотеку запрашивал весь список элементов на каждый импортируемый элемент.
- Поиск (Ctrl+K) с пустым запросом читал все workflow всех проектов; теперь показывает подсказку.
- `DB.keys()` никто не вызывал, и он делал лишний запрос к папке данных.
