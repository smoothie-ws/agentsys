# AI primitives

`POST llm` is the sole model entry point. It accepts `prompt` or `messages`, optional `provider`, `model`, `retry:{max,backoff,retry_on}`, `timeout`, `schema` and `format_attempts`. Default retry: two retries after 100/200 ms for network errors, 429 and 500/502/503/504. Each attempt has a 60 s timeout. Retries and JSON correction attempts consume budget and produce individual trace entries. Structured output supports object/array/scalar types, properties, required keys, enum, items, additionalProperties and numeric minimum/maximum. Unsupported schema features should not be relied on.

Run budgets are `{calls,tokens,cost,ms}`; omitted dimensions have no cap. Defaults are 100 calls, one million tokens, cost 10 and one week. Provider `prices:{input,output}` are currency units per million tokens, default zero. Configure actual rates to enforce money limits. Before each call, tokens and cost are reserved under `exclusive`, using prompt UTF-8 bytes plus the output limit; the actual usage settles that reservation. Failed attempts still count as calls. Initiative budgets share the same reservation lock across runs. `budget_exceeded` fails the run by default; `budget_policy:"approval"` suspends it for a budget increase when the node can request approval. The approved budget is supplied in `POST approvals/{id}` as `budget`.

`llm_call` records provider/model, parameters, prompt/response hashes and lengths, usage, cost, duration, attempt and error. Full redacted text is in `blobs/<sha256>`; `trace_blobs:false` disables these blobs. `blob_retention_ms` defaults to one week; scheduler ticks remove expired blobs. Provider credentials remain in the host. Trace redaction removes bearer credentials and named token/password/secret values; avoid placing unrelated sensitive personal information in prompts if it should not be retained.

`await node.wait({approval:{question,options?,timeout?,expires_at?,default?,context_ref?}})` creates a durable Approval and frees the Worker. Defaults: approve/reject, 24 hours, reject. `default:"escalate"` leaves an escalated item for a person. `POST approvals/{id} {answer,comment}` answers once and resumes the same invocation. `node.resumed.value` includes `answer`, `comment` and `approved`; code must check the answer before performing an effect. Manual resume cannot bypass an approval.

Settings API: `default_budget`, `allowed_models` (`Provider/model`), `budget_policy`, `trace_blobs`, `blob_retention_ms`. See `examples/ai-nodes.json` for model calls, JSON output, routing, summarization, budget checks, Ask human and a bounded Tool-use loop. Tests use a fake HTTP response and never contact a paid provider.
