отсюда не реализована** — это материал для следующего планирования. Приоритеты: **P1** —

## Что проверено и отброшено

- **Массовая консолидация CSS по одинаковым телам правил.** Точных дублей почти нет (1 группа,
  3 строки); объединение разных селекторов меняет каскад. Нужен визуальный стенд (I-D3).
- **Удаление «мёртвых» функций.** Статический скан 756 объявлений не нашёл ни одной функции без
  использования; удалять «на глаз» нельзя.
- **Сокращение JS на −500 строк за счёт реформата.** Запрещено условиями задачи и не даёт
  реального выигрыша.
- **Кэш снапшота без версии Library.** Отброшен до появления надёжной инвалидации (I-C15).
