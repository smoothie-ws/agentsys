# Ревизия интерфейса, 22 октября 2026

Задача: проверить отзывчивость и анимации, сократить и упорядочить код, сделать интерфейс мягким и современным.

## Что изменено

- **Стили переписаны с нуля.** 10 CSS-файлов (3 556 строк, 73 КБ) заменены семью (2 796 строк, 56 КБ). Файлы-«переопределения» (`refinements`, `docs-and-menus`, `panels-and-rails`, `side-panel`) удалены, правила лежат в файле своей области. Добавлен `inspector.css`.
- **Дизайн без обводок и линий.** Поверхности различаются тоном (`--panel`, `--card`, `--field`, `--well`), а не рамками. Тени и размытие включаются настройкой Effects, без неё всё плоское и сплошное.
- **Единое поведение элементов.** Наведение: мягкая подсветка. Нажатие: уменьшение до 0,97. Фокус с клавиатуры: кольцо, при клике мышью его нет. Курсоры и состояния `disabled` общие для всех кнопок и полей.
- **Анимации.** Только `opacity` и `transform` там, где это безопасно. Меню и подменю появляются плавным затуханием, диалоги всплывают, боковая панель и список проектов анимируют ширину и прозрачность. Узлы и рамки не анимируют `transform`, поэтому не отстают при перетаскивании. При выключенном Motion или `prefers-reduced-motion` анимаций нет.
- **Без лишних полос прокрутки.** На ширинах 1500, 900 и 600 px у страницы нет горизонтального и вертикального переполнения.

## Код и логика

- Хелпер `store` заменил около дюжины блоков `try/catch` вокруг `localStorage`.
- Одна функция совместимости портов (`compatible` из `schema.js`) вместо двух копий. Поиск конечных узлов для запуска один и для кнопки Run, и для запуска с карточки проекта.
- Удалены хлебные крошки, `.divider`, класс `stale`, мёртвая переменная выделения.
- На узких экранах (до 900 px) панель свойств по умолчанию свёрнута, раньше она закрывала холст. Подсказка «How it works» сокращена.

## Правки по обратной связи (тот же день)

- Точка reroute больше не прыгает при наведении: масштаб убран, наведение меняет только цвет и мягкое свечение.
- Отклик усилен: подсветка при наведении 16% (было 10%), нажатие 24%, кнопки приподнимаются на 1 px и «проседают» при нажатии, активные пункты навигации подкрашены акцентом.
- API: папки по умолчанию свёрнуты, раскрываются метод из адреса или клик.
- Glassmorphism возвращён: полупрозрачные боковые панели, карточки, узлы и меню с размытием поверх мягкого свечения фона. С выключенным Effects всё снова сплошное.
- Правая панель: в свёрнутом виде не обрезается (колонка учитывает отступ), справа нет зазора (убран `scrollbar-gutter` в редакторе).
- Иконки import и export поменяны местами (import: стрелка внутрь, export: стрелка наружу).
- Library: Import и Export убраны из отдельных кнопок и лежат в меню «+» вместе с созданием (Import…, Export selected, Export all). Кнопка «+» прижата к правой границе во всех разделах.
- Индикатор сворачивания панелей одинаковый: при перетаскивании за порог панель становится полупрозрачной (раньше слева менялся цвет границы).
- Граф при открытии вписывается в окно (fit to view). Возврат на уже открытую в этой сессии вкладку восстанавливает прежний масштаб и положение.

## Вторая серия правок

- Градиентный фон убран: фон плоский. Стекло стало прозрачнее (панели 30%, узлы и карточки 42%, меню 56%) с меньшим размытием (10 px и 5 px).
- Del при выделенных соединениях отсоединяет их (раньше клавишу перехватывало удаление узлов, и ничего не происходило).
- Reroute принимает тип своего провода: по источнику, а без источника по приёмнику. Через него нельзя соединить несовместимые порты (например, text с boolean). Типизация считается в `snapshot.js`, тест добавлен.
- Строки слотов на узле больше не подсвечиваются при наведении: подсвечивается только сокет, за который можно тянуть провод.
- На миникарте узлы окрашены цветом узла: выбранным цветом, акцентным для заметок и Complex Nodes, иначе нейтральным.
- В списке проектов у проекта и workflow появляется кнопка «⋯» при наведении. Меню то же, что на карточках (Rename, Duplicate, Settings, Delete); переименование из списка идёт через небольшой диалог.
- Из меню узлов и групп Custom Nodes убраны Import и Export. Они остались только в меню «+» раздела.
- Больше отклика при наведении: кнопки и иконки слегка увеличиваются (1.03 и 1.14), карточки приподнимаются и растут на 1.5%.
- Поле ввода при фокусе подсвечивается тоном, без кольца.

## Растягивание групп

Края и углы рамки группы снова захватываются: при переписывании стилей у рамки пропали `pointer-events: auto` для ручек, и растягивание не работало. Добавлена подсветка края при наведении и проверка в `tests/browser_smoke.py`. Узлы по-прежнему перетаскиваются в группу (в том числе в растянутую часть), рамка при этом подсвечивается.

## Вложение Complex Nodes и групп

Свёрнутые Complex Nodes и рамки групп (в том числе раскрытых Complex Nodes) теперь можно перетаскивать в другую группу: рамка-цель подсвечивается, при отпускании меняется родитель группы. Вынуть наружу можно через зону сверху холста. Раньше при перетаскивании учитывались только обычные узлы. Корневая группа редактора Custom Node по-прежнему не вкладывается.

## Фон и тёмные темы

На фон добавлен один слабый радиальный градиент цвета accent (`--glow` в `tokens.css`; с выключенным Effects фон плоский). Темы Graphite и Dark сделаны темнее для контраста с панелями: Graphite `#06080b` / `#14181f`, Dark `#101010` / `#202020`. Уже сохранённые настройки со старыми цветами этих двух тем переносятся на новые автоматически (`upgradeStyle` в `preferences.js`).

## Вкладки, active/hover, градиент, карточки проектов

- Вкладки: у неактивных только иконка и название; кнопка закрытия (или значок закрепления) плавно выезжает при наведении; активная вкладка показывает всё (название проекта, крестик).
- Новый токен `--current` (accent 26%) для открытого/выбранного элемента — заметно сильнее `--hover`. Применён в боковом меню, дереве проектов, вкладках, Library, разделах настроек, дереве API, табах инспектора и т.п.
- Градиент фона: плавная «ease»-кривая из нескольких остановок + тонкий шум `--noise` (убирает ступеньки), слабее прежнего.
- Карточка проекта: кнопка «⋯» теперь поверх миникарт (`isolation` у превью), миникарты веером с растущим поворотом (`rotate(--layer × 2.2°)`).

## Раунд 8

- Вкладки перерисовываются «на месте» (элементы переиспользуются), поэтому расширение активной и сжатие остальных анимируется; название проекта у активной вкладки выезжает плавно.
- Градиент фона: по центру сверху, ещё слабее (`--glow` в `tokens.css`).
- Ручки перетаскивания границ панелей теперь снаружи панелей (`overflow: clip` + `overflow-clip-margin`).
- Превью карточек показывают цвета узлов и групп; миникарта редактора — связи (цвет по типу данных).
- Рядом с Run больше нет счётчика узлов (остаётся только «N failed»).
- Кнопки «Run» и «⋯» на карточках — в правом нижнем углу.
- Library: переключение разделов не перерисовывает страницу, а меняет контент и подсветку (как в Settings). Навигация разделов теперь общая: `sectionNav` / `selectSection` в `pages/shared.js`.
- Code: `drag()` вынесен в `app/helpers.js` и используется и холстом, и ресайзом панелей; `panelResize` и `sidebarResize` собираются из `resizeHandle` + `drag` (общий код ручки и жеста).
- Active всегда отличается от hover и при наведении на сам активный элемент (кнопки: правило в конце `controls.css`).
- Settings → Appearance → Graph Editor: стиль соединений (Bezier / Straight / Right angles / Rounded right angles), толщина, изгиб Bezier, скругления узлов и групп (`GRAPH_DEFAULTS`, `GRAPH_RANGES`, `wirePath` в `canvas/render.js`).
- Зона «Drop here to take out of the group» теперь появляется над верхней границей группы, из которой тащат узел (а не вверху холста).

## Раунд 9

- Зона «take out of the group» — штрихованная.
- Reroute: невидимые области слева (отвязать входящую связь) и справа (протянуть новую) выступают за точку; середина точки по-прежнему перетаскивает её.
- Undo/Redo — справа, рядом с Run.
- Иконка уже открытого раздела правой панели её не закрывает (закрывает крестик). «Log» → «Activity».
- Settings (и Project settings) сохраняются сами через общий `autoForm` (`autosave` в `pages/settings.js`); вместо Save — «Restore defaults». Статус «Saved» — в шапке.
- Инспектор: убраны позиция/размер и combobox подключения входов/выходов и привязки портов группы (всё делается на холсте). У каждого слота слева кружок цвета типа (`typeDot`). Привязка порта группы сохраняется в `data-bound` строки.
- Размытие: стекло меню и диалогов вынесено в `::before` (предок с opacity < 1 отключает backdrop-filter у потомков, поэтому раньше blur появлялся только в конце fade); стекло и содержимое появляются рядом.
- Контекстные меню плавно исчезают (`closePopup` → класс `.closing`; `fade-out` в `tokens.css`).

## Раунд 10

- Вкладки есть у всех страниц: Projects, проект, настройки проекта, Library (с текущим разделом), Settings, API (`Tabs.pageTab` в `app/tabs.js`, открываются из `render()` в роутере). Активная вкладка отмечена короткой акцентной полоской снизу, а не заливкой — чтобы не путать с кнопками под вкладками.
- Связь, перетаскиваемая на reroute, подсвечивает точку кольцом (`.drop-target`).
- Штриховка зоны тоньше. Убраны подсветки краёв при ресайзе узлов/групп, ресайз больше не выделяет узел.
- Правая панель: растягивается за границу и в свёрнутом виде (как левая; `panelResize` получил `expand`/`isCollapsed`); панель — отдельная скруглённая карточка с отступом справа (у свёрнутой «рейки» больше нет косого среза).
- Свойства: строка слота — `● тип имя … значение`; куда подключен слот — кликабельная ссылка на узел (для выходов — список получателей).
- Default порта группы: контрол следует за типом (text / number / int — поле, boolean — on/off) и меняется сразу при смене типа, а не после повторного открытия.

## Раунд 11

- Вкладки без фона (и при наведении): при наведении появляется половина полоски, полупрозрачная; у открытой — вся.
- Вкладка хранит состояние: адрес с запросом (раздел и элемент Library, раздел Settings — `section`, прокрутка — `scroll`). Открытие страницы из сайдбара/ссылки, у которой уже есть вкладка, возвращает эту вкладку как она была (`Tabs.resolve` в `go()`); внутри страницы (смена раздела Library) работает как раньше.
- Сайдбар: проекты — просто названия со счётчиком workflow (на наведении заменяется на «⋯»), workflow — с точкой под шевроном, имена выровнены; подпись «PROJECTS» — тихая заглавная метка.

## Round 12

- **Slot editors** (Script inputs, Complex Node inputs/outputs) use the row of every other node's slots: type dot, type, bold name, value on the right. The type and name are fields that look like text until pointed at; the remove cross appears on hover.
- **Links in notifications**: `toast()` text accepts `[label](/page/path)` (opens the page) and `[label](node:ID)` (selects that node on the canvas), see `linkedText()` in `js/app/dialogs.js`. Used by: project duplicated, workflow run from a card, run with errors, "Edit it in the Library".
- Tabs: pointing at a tab draws no bar any more; closing a tab fades and shrinks it (`Tabs.dismiss`) while the tabs to its right glide over.

## Round 13

- Node headers show an icon left of the name (by node type; a Complex Node uses the icon chosen in the Library).
- **Collapse a node**: the chevron in the header (shown on hover, always on a collapsed node), or "Collapse / Expand" in the context menu. A collapsed node keeps its icon, name, state marks (pin) and slots; values, code, previews and notes are hidden. Stored as `folded` next to `pinned` in the node style (`PUT node-style`), copied and pasted with the node, undoable.
- Library: Export is its own button beside "+" (exports the whole section); one item exports from its form. The "+" menu is create / import / restore.
- **Built-in items**: `builtin/*.json` (Library exports, one file per kind: providers, skills, nodes) are imported once on the first run (`seedBuiltins`, flag `builtins_seeded`). Afterwards they are ordinary items. "Restore built-in items" adds back the missing ones by kind and name and never overwrites. See `builtin/README.md`.

## Round 14

- Deleting a Custom Node group in the Library deletes everything inside it: its groups and its Custom Nodes (with their graphs and open tabs). The dialog counts them.
- Export / import keep the group of a Custom Node (`payload.folder`), so a tree exported from one Library comes back as it was. (Empty groups and group icons are not part of the export.)
- A node with a chosen colour is filled with exactly that colour (it was a 6 % tint); its text and fields switch between light and dark to stay readable (`.node.colored`, `inkOn()`). Groups keep their light tint.
- The editor toolbar no longer has "Add node" and "Node": use the canvas context menu (right-click), or the Add button on an empty canvas.
- Built-in items are split by kind (see `builtin/README.md`).
