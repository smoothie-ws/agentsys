# Единая древовидная навигация и карточки, 23 октября 2026

Задача: интерфейс должен работать одинаково в любом разделе — вторая панель это дерево, страница рядом показывает детей открытой строки карточками; карточки проектов, workflow, ресурсов и групп должны быть в одном стиле с узлами и группами на канвасе.

## Что сделано

- **Дерево во второй панели для всех разделов.** Projects: проекты → их workflow. Library: Providers / Skills / Custom Nodes → их элементы (у Custom Nodes — группы → узлы). API и Settings остались деревом/вкладками, но строятся теми же строками `.subnav-row`. Строка с детьми имеет шеврон и раскрывается с анимацией; раскрытое запоминается (`agentsys-nav-open`). Открытая строка раскрывает своих предков сама.
- **Строка «All projects» убрана.** Список проектов — это строка Projects в первой панели.
- **Страница = дети открытой строки в виде карточек.** Projects → карточки проектов; проект → карточки workflow (с кнопкой Run); Library → карточки видов; Library → Skills → карточки скиллов; Custom Nodes → карточки групп и узлов; элемент открывается в форме (`/resources/<вид>/<id>`, новый — `/resources/<вид>/new`) или в редакторе графа. Над каждой страницей одинаковая шапка: путь, заголовок, действия (`pageHead`).
- **Меню и действия общие.** «⋯» у строки панели и у карточки открывает одно и то же меню (`menuItems` в `nav.js`): переименовать, дублировать, переместить, экспорт, удалить; «+» в шапке панели создаёт то, что относится к открытому разделу. Узел Custom Node перетаскивается строкой на строку группы.
- **Скольжение подсветки.** Подсветка — один элемент вне перерисовываемого списка. Раньше при любом пересчёте (раскрытие группы, ресайз, скролл) она перепрыгивала без анимации, и при смене подраздела скольжения не было. Теперь `placePill` различает «другая строка» (плавный переезд) и «та же строка сместилась» (липнет к ней без задержки); при свёрнутой панели строка внутри закрытой группы представлена строкой группы.
- **Единый стиль карточек и канваса.** Карточки используют поверхность узла (`color-mix` текста на стекле карточки), радиус `--node-radius`, общую тень `--card-shadow`, тот же вес заголовка (640; у заголовка группы на канвасе тоже), превью рисуются в тонах канваса (узлы светлее фона, группы — лёгкая вуаль, Complex Node — в акценте, у узлов тонкая контурная линия, чтобы они читались и в светлой теме).
- **Ctrl+K** находит элементы Library и группы Custom Nodes (подсказка «Library · Skills»).
- **Полоса у границы панели** — это подсветка при наведении (2 px вместо прежнего 8-пиксельного блока), в покое её нет.

## Файлы

Новый `js/app/nav.js` (дерево, подсветка, меню), `shell.js` сокращён до панелей, поиска и запуска. Переписаны `pages/library.js` (обзор, список, форма элемента), `pages/projects.js`, куски `settings.js`, `api-docs.js`, `shared.js` (`pageHead`, `card`, превью), `router.js` (маршруты `resources/<вид>/<id>`, `?folder=`), `tabs.js` (ключи страниц Library), CSS второй панели и карточек.
